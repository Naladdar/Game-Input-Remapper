# Changelog

## 1.0.0 - 2026-08-26

- First public release.
- English-first bilingual UI (English/German).
- Default Crimson Desert profile.
- Raw Input device-aware source learning.
- Configurable 1-2000 ms key press duration, default 100 ms.
- Per-mapping Auto fire with configurable pause.
- Multiple game/setup profiles stored in `profiles.ini`.
- Steam/direct EXE launch configuration per profile.
- Raw Input diagnostics.
- Desktop launcher and shortcut helper.
- Automatic import of legacy Crimson Desert v8/v9 registry settings on first run.

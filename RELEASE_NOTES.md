# Game Input Remapper v1.0.0

Initial public release. The default profile is tuned for Crimson Desert and Razer Naga/Synapse-style keyboard mappings.

Recommended Crimson Desert starting values:
- Key press duration: 100 ms
- Auto fire: optional
- Auto-fire pause: 0 ms is supported and was tested successfully

Read `README.md` before first use. German instructions are in `README_DE.md`.
